# Harness strategies

Generated by aia-harness for a **Python** project (commands source: ecosystem default).

## Lint & format
- Lint: `ruff check`
- Format: `ruff format`

## Compilation / typecheck
- `pyright`

## Language server
- Provided by the `pyright-lsp` plugin (installed at user level).
- There is deliberately no project-level LSP config. Claude Code reads `.lsp.json` only from
  inside a plugin directory — a repo-root one is inert — and `lspServers` is not a valid
  `settings.json` field (the native validator rejects it as an unrecognized key). Configuring a
  project-specific language server requires shipping it as a plugin.

## Unit testing
- `OBSIDIAN_VAULT_PATH=/path/to/vault pytest`

## Canonical command reference
- **Install:** `uv sync --extra dev`
- **Lint:** `ruff check`
- **Format:** `ruff format`
- **Typecheck:** `pyright`
- **Test:** `OBSIDIAN_VAULT_PATH=/path/to/vault pytest`
- **Build:** `uv build`
- **Run/Dev:** `python`
